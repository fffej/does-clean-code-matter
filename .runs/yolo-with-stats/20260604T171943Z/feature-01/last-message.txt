Implemented the CSV round-trip feature.

What changed:
- The CLI now accepts a single CSV file path and streams its bytes back to stdout unchanged.
- `slice data.csv` with no transformation now preserves:
  - header row
  - row order
  - column order
  - cell contents exactly
- Added a focused regression test that verifies byte-for-byte round-trip behavior.
