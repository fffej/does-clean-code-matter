What changed:

  - `groupby <column> sum <column>`
  - preserves first-seen group order
  - errors when any referenced column is missing
  - errors when `sum` sees a non-numeric value
  - emits data rows only, with no header row
  - formats summed decimals canonically, so `10.00` prints as `10`
