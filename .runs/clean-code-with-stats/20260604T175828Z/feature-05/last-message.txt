What it does:
- Adds `slice <csv-file> head <count>`.
- Preserves the header row.
- Streams only the first `N` data rows in original order.
- Outputs all rows if the file has fewer than `N` data rows.
- Fails with an error for zero or negative counts.
- Updates usage text to include `head`.
